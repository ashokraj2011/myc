# code-hex — Quick fix scope and plan

This short checkpoint states what the fix must do and where it lands before any code changes.
One reviewer signs it off; Implement then has to meet exactly these claims.

## Problem and fix

The Standard calculator cannot convert a keyed decimal integer to hexadecimal. Add a `HEX`
button that converts only a plain positive integer currently keyed in the expression and shows
the equivalent value with the exact `0x` prefix; unsupported input shows `Error`.

## Requirements

| Clause | Requirement |
|---|---|
| [code-hex:REQ-001] | The Standard calculator keypad shall expose a button whose visible label is exactly `HEX`. |
| [code-hex:REQ-002] | Pressing `HEX` with a plain positive decimal integer keyed shall show its value-equivalent hexadecimal representation with the exact `0x` prefix. Hexadecimal letter case is not prescribed. |
| [code-hex:REQ-003] | Pressing `HEX` with empty, zero, negative, decimal, or compound-expression input shall show `Error` in the result display. |
| [code-hex:REQ-004] | The delivered change shall include retained visual evidence of the visible `HEX` button and a successful `16` to `0x10` conversion. |

## Acceptance criteria

| Clause | Requirement | Observable outcome |
|---|---|---|
| [code-hex:AC-001] | `code-hex:REQ-001` | In Standard mode, the keypad visibly contains a button labeled exactly `HEX`. |
| [code-hex:AC-002] | `code-hex:REQ-002` | Given `16` is keyed as the complete input, pressing `HEX` shows `0x10` in the result display. |
| [code-hex:AC-003] | `code-hex:REQ-003` | Each unsupported input class—empty, zero, negative, decimal, and compound expression—shows `Error` when `HEX` is pressed. |
| [code-hex:AC-004] | `code-hex:REQ-004` | Retained visual evidence shows the visible `HEX` button and the displayed `0x10` result after converting keyed input `16`. |

## Scenarios

### S-001 — Convert a positive integer

- **Given** the calculator is in Standard mode and `16` is the complete keyed input
- **When** the user presses `HEX`
- **Then** the result display shows `0x10`

### S-002 — Reject unsupported input

- **Given** the current input is empty, zero, negative, decimal, or a compound expression
- **When** the user presses `HEX`
- **Then** the result display shows `Error`

### S-003 — Find and inspect the conversion control

- **Given** the calculator is in Standard mode
- **When** the keypad is displayed
- **Then** a button labeled exactly `HEX` is visible
